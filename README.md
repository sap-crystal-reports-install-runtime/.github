## Troubleshooting Common Issues

Install issues? Verify the runtime version before installing the designer, since mismatches cause blank reports.  
Performance problems? Install the correct bitness of the database driver on both designer and client machines.  
License/activation? Confirm the designer licence key and seat count before activation.  
Compatibility? Recompile reports after a major version upgrade rather than copying old files.  
Update failures? Check that the install account has rights to register the runtime components.
